# Keepsake 전체 QA 체크리스트

> 기준: 2026-11-02 코드 (앱 1.0.0, Expo SDK 54) · 기능이 바뀌면 이 문서도 함께 고친다.
> 제품 규칙과 배경은 `docs/PLAN.md`, 스토어 문구는 `docs/store/`, 약관 웹 게시본은 `backend/app/legal/{ko,en}/`에 있다.

## 1. 사용법

- 각 항목을 iOS와 Android에서 따로 확인하고, `iOS`·`AOS` 칸의 `☐`를 결과로 바꾼다.
  - `P` 통과 / `F` 실패 / `N` 해당 기기에서 확인 불가(사유를 메모). `—`는 그 플랫폼에 해당 없음.
- 실패하면 항목 ID, 기기·OS, 재현 순서, 화면 녹화를 이슈로 남긴다.
- 등급
  - **P0** 사진·기록·결제가 잘못될 수 있음. 하나라도 실패하면 출시하지 않는다.
  - **P1** 핵심 흐름 오류. 출시 전에 고친다.
  - **P2** 불편·표시 문제. 판단해서 다음 버전으로 미룰 수 있다.
- 시간이 부족하면 §4의 스모크 → 모든 P0 → P1 → P2 순서로 진행한다.
- **사진 삭제 항목은 반드시 테스트 전용 기기나 테스트 전용 계정의 사진으로 한다.** iCloud 사진을 켠 개인 계정에서는 다른 기기의 사진도 함께 지워진다.

## 2. 테스트 환경

### 2.1 기기

| 플랫폼 | 필요한 환경 | 확인하는 것 |
|---|---|---|
| iOS | 최소 지원 버전(15.5)에 가장 가까운 기기 1대 | 하한 버전 동작 |
| iOS | 최신 iOS 실기기 1대, iCloud 사진 켬 | iCloud에만 있는 사진, 최근 삭제된 항목 |
| iOS | 2번째 기기 (같은 Cloud 계정) | 기기 간 동기화·복원 |
| Android | Android 10 이하 1대 (에뮬레이터 가능) | 휴지통 없이 바로 삭제되는 경로 |
| Android | Android 11~13 1대 | 기기 휴지통, 사진 권한 |
| Android | Android 14 이상 실기기 1대 | '일부 사진만 허용', 알림 |
| Android | 2번째 기기 (같은 Cloud 계정) | 기기 간 동기화, iOS ↔ Android 복원 |

시뮬레이터로 대신할 수 없는 항목: 알림 수신·누르기, 실제 삭제와 OS 확인 창, 두 손가락 확대·축소, iCloud 사진, 구매.

### 2.2 빌드

- [ ] **네이티브 설정을 반영해 새로 빌드했다.** 패키지 제거와 `app.json` 변경이 있었으므로 예전 개발 빌드로 테스트하지 않는다.
- [ ] 1차는 EAS `preview`, 최종은 `production` 프로필(TestFlight / Play 내부 테스트)로 확인한다.
- [ ] 설정 화면 맨 아래의 버전·빌드 번호를 결과에 적는다.
- [ ] 서버 환경을 적는다. 결제 연결 전이면 `CLOUD_BILLING_ENABLED=false` (로그인한 계정을 구독 중으로 취급)이고, §13은 결제 연결 후에만 진행한다.

### 2.3 준비할 데이터

- 사진: 오늘 찍은 사진, 일주일·한 달·1년 이상 지난 사진, 위치 정보가 있는 사진과 없는 사진, 해외 시간대에서 찍은 사진, 세로·가로·파노라마, HEIC(iOS)·JPEG·PNG
- 많은 양: 고르기 범위에 500장 이상, 1000장 이상이면 더 좋다
- 몇 년 전 **오늘과 같은 월·일**에 찍은 사진 (그날의 기억 확인용)
- iOS: 즐겨찾기 사진, iCloud에만 있는 사진 (기기 저장 공간 최적화)
- 메신저로 받거나 PC에서 넣은, **촬영 날짜가 지난** 사진 (놓친 사진 확인용)
- Cloud: Apple 계정, Google 계정 각 1개 + 다른 계정 1개 (계정 전환 확인용)

## 15. 버그가 아닌 알려진 동작

실패로 기록하지 않는다. 바꾸려면 `PLAN.md`의 결정을 먼저 고친다.

- 앱은 사진을 복사하지 않으므로, Local에서는 기기 사진첩에서 지운 사진이 기록에서도 보이지 않는다.
- Android는 즐겨찾기 여부를 알 수 없어 즐겨찾기도 정리 대상에 나온다.
- Android 10 이하는 삭제하면 되돌릴 수 없다.
- 같은 사이에 사진을 지우고 같은 수만큼 넣으면 놓친 사진을 찾지 못한다.
- 한 번에 200장 넘게 늘면 놓친 사진으로 묶지 않는다.
- 알림의 사진 수는 예약할 때 정해지므로, 앱을 오래 열지 않으면 실제와 다를 수 있다. 두 번째 알림부터는 일반 문구다.
- Local은 기기를 바꾸면 기록이 이어지지 않는다.
- 올리기로 복사한 기록은 Local 기록과 따로 고쳐진다. Local 앨범은 복사되지 않는다.
- Apple 로그인은 iOS에만 있다. Apple 계정으로 쓰던 Cloud 데이터는 현재 Android에서 받을 수 없다.
- 구독 전에 기기에서 지운 사진은 Cloud에 올릴 수 없다.
